# 连接器徽标归属说明

此处展示的第三方标志仅用于标识通过 OpenScience 可获取的科学数据源。每个标志均归其各自所有者所有，其展示不构成任何背书或推荐。

每个展示标志的官方网站及来源 URL 记录于 [`src/data/connectors.ts`](../../src/data/connectors.ts) 中。

## 官方备用标志

- **NCBI Gene** 与 **NCBI dbSNP：** 其官方页面将数据库名称以样式化文本形式呈现，并未提供独立的产品图片，因此保留了 NCBI 共用的网站图标。
- **SIFTS：** 其官方页面展示了 EMBL-EBI、PDBe 和 UniProt 的标志，但未提供独立的 SIFTS 图片，因此保留了 EMBL-EBI 共用的网站图标。
