# 研究查询技能

本技能通过 OpenRouter 使用 Perplexity 的 Sonar Pro 搜索模型，提供实时研究信息查询。

## 设置

1. **获取 OpenRouter API 密钥：**
   - 访问 [openrouter.ai](https://openrouter.ai)
   - 创建账户并生成 API 密钥
   - 向账户添加积分

2. **配置环境变量：**
   ```bash
   export OPENROUTER_API_KEY="your_api_key_here"
   ```

3. **测试设置：**
   ```bash
   python scripts/research_lookup.py --model-info
   ```

## 使用方法

### 命令行用法

```bash
# 单次研究查询
python scripts/research_lookup.py "Recent advances in CRISPR gene editing 2024"

# 带延迟的批量查询
python scripts/research_lookup.py --batch "CRISPR applications" "gene therapy trials" "ethical considerations"

# Claude Code 集成（自动调用）
python lookup.py "your research query here"
```

### Claude Code 集成

当您执行以下操作时，研究查询工具会在 Claude Code 中自动可用：

1. **提出研究问题：** “研究量子计算的最新进展”
2. **请求文献综述：** “查找关于气候变化影响的当前研究”
3. **需要引用：** “关于 Transformer 注意力机制的最新论文有哪些？”
4. **获取技术信息：** “流式细胞术的标准方案”

## 功能特性

- **学术聚焦：** 优先选择同行评审的论文和权威来源
- **最新信息：** 重点关注近期出版物（2020-2024）
- **完整引用：** 提供包含 DOI 的完整书目信息
- **多种格式：** 支持多种查询类型和研究需求
- **高搜索上下文：** 始终使用高搜索上下文进行更深入、更全面的研究
- **质量优先：** 自动优先选择顶级期刊中高被引论文
- **成本效益：** 每次研究查询通常花费 0.01-0.05 美元

## 论文质量优先级

本技能**始终优先选择高影响力、有重要学术价值的论文**，而非冷门出版物。结果按以下标准排序：

### 基于引用的排名

| 论文年限 | 引用阈值 | 分类 |
|-----------|-------------------|----------------|
| 0-3 年 | 20+ 次引用 | 值得关注 |
| 0-3 年 | 100+ 次引用 | 高影响力 |
| 3-7 年 | 100+ 次引用 | 重要 |
| 3-7 年 | 500+ 次引用 | 里程碑式 |
| 7 年以上 | 500+ 次引用 | 开创性 |
| 7 年以上 | 1000+ 次引用 | 奠基性 |

### 期刊质量等级

来自更高级别期刊的论文始终优先：

- **第一梯队（最高优先级）：** Nature、Science、Cell、NEJM、Lancet、JAMA、PNAS、Nature Medicine、Nature Biotechnology
- **第二梯队（高优先级）：** 高影响力期刊（IF>10）、顶级会议（机器学习/人工智能领域的 NeurIPS、ICML、ICLR）
- **第三梯队（良好）：** 受认可的专业期刊（IF 5-10）
- **第四梯队（谨慎使用）：** 其他同行评审期刊

### 作者声誉

本技能优先选择以下作者的论文：
- 具有较高 h 指数的资深研究人员
- 知名机构的成熟研究团队
- 在第一梯队期刊发表多篇论文的作者
- 具有公认专业能力的研究人员（获奖者、编委会成员）

### 相关性优先级

1. 直接回答研究问题的论文
2. 具有适用方法/数据的论文
3. 间接相关的论文（仅限顶级期刊或高被引论文）

## 响应格式

每项研究结果包括：
- **摘要：** 关键发现的简要概述
- **关键研究：** 3-5 篇最相关的近期论文
- **引用：** 完整的书目信息
- **使用统计：** 用于成本跟踪的 Token 使用量
- **时间戳：** 执行研究的时间

## 与科学写作的集成

本技能通过以下方式增强科学写作流程：

1. **文献综述：** 为引言部分提供当前研究
2. **方法验证：** 根据当前标准验证方案
3. **结果对比：** 与近期类似研究进行比较
4. **讨论支持：** 为论点提供最新证据
5. **引用管理：** 提供格式规范的参考文献

## 故障排除

**“未找到 API 密钥”**
- 确保已设置 `OPENROUTER_API_KEY` 环境变量
- 检查您的 OpenRouter 账户中是否有积分

**“模型不可用”**
- 验证您的 API 密钥是否有权限访问 Perplexity 模型
- 查看 OpenRouter 状态页面了解服务问题

**“超出速率限制”**
- 使用 `--delay` 选项在请求之间添加延迟
- 检查您的 OpenRouter 账户限制

**“无相关结果”**
- 尝试更具体或更宽泛的查询
- 包含时间范围（例如，“2023-2024”）
- 使用学术关键词和技术术语

## 成本管理

- 通过 OpenRouter 仪表板监控使用情况
- 典型成本：每次研究查询 0.01-0.05 美元
- 支持批量处理多个查询
- 考虑查询的具体性以优化 Token 使用

本技能专为学术和研究目的而设计，提供高质量、带引用的信息以支持科学写作和研究活动。
