用于进行严谨市场分析的模板和框架。

## 市场规模框架

### TAM/SAM/SOM 分析

**总体可寻址市场（TAM）** 代表在实现100%市场份额的情况下可获得的总体收入机会。

#### 自上而下方法
```
TAM = 行业总收入（来自市场研究报告）

示例：
- 全球AI软件市场（2024年）：1840亿美元
- 来源：Gartner、IDC 或类似机构
```

#### 自下而上方法
```
TAM = 潜在客户数量 × 每位客户的平均收入

示例：
- 全球企业数量：4亿
- 目标细分市场（大型企业）：50,000
- 解决方案年均支出：50万美元
- TAM = 50,000 × 50万美元 = 250亿美元
```

**可服务可寻址市场（SAM）** 代表在产品/服务能力范围内可以服务的 TAM 部分。

```
SAM = TAM × 适用细分市场百分比

示例：
- TAM：250亿美元
- 地理限制（仅北美）：40%
- 产品匹配度（仅企业）：60%
- SAM = 250亿 × 40% × 60% = 60亿美元
```

**可获得可服务市场（SOM）** 代表可实现的实际市场份额。

```
SOM = SAM × 可实现市场份额百分比

示例：
- SAM：60亿美元
- 保守市场份额（5%）：3亿美元
- 基准市场份额（10%）：6亿美元
- 乐观市场份额（15%）：9亿美元
```

### 增长率计算

#### CAGR（复合年增长率）
```
CAGR = (期末值 / 期初值)^(1/n) - 1

其中 n = 年数

示例：
- 2020年市场规模：100亿美元
- 2024年市场规模：180亿美元
- n = 4年
- CAGR = (18/10)^(1/4) - 1 = 15.8%
```

#### 同比增长率
```
同比增长率 = (本年度 - 上一年度) / 上一年度 × 100

示例：
- 2023年：150亿美元
- 2024年：180亿美元
- 同比增长率 = (18-15)/15 × 100 = 20%
```

## 波特五力分析

### 框架模板

对每种力量进行评估：**高**、**中** 或 **低**

#### 1. 新进入者威胁

**评估因素：**
| 因素 | 评估 | 备注 |
|--------|------------|-------|
| 资本要求 | 高/中/低 | 进入所需资金 |
| 规模经济 | 强/中/弱 | 现有企业优势 |
| 品牌忠诚度 | 高/中/低 | 客户转换成本 |
| 分销渠道获取 | 容易/中等/困难 | 渠道可用性 |
| 监管壁垒 | 高/中/低 | 许可、认证 |
| 专有技术 | 关键/重要/次要 | 知识产权和专有技术 |
| 预期报复 | 激烈/中等/温和 | 现有企业反应 |

**总体评估：** [高/中/低]

**关键洞察：** [影响总结]

## 风险评估框架

### 风险识别

#### 风险类别
1. **市场风险**：需求变化、价格压力、市场转变
2. **竞争风险**：新进入者、竞争对手行动、颠覆
3. **监管风险**：新法规、合规要求
4. **技术风险**：技术过时、安全、集成
5. **运营风险**：供应链、质量、产能
6. **财务风险**：汇率、利率、
