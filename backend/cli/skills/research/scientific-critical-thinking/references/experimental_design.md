# 实验设计核对清单

## 研究问题构建

### 问题是否构建良好？
- [ ] **具体性：** 明确定义的变量及其关系
- [ ] **可回答性：** 能够通过现有方法进行研究
- [ ] **相关性：** 针对知识空白或实际需求
- [ ] **可行性：** 资源、时间和伦理考量允许开展
- [ ] **可证伪性：** 若假设错误则可以被证明

### 是否已进行文献综述？
- [ ] 明确已知的研究成果
- [ ] 发现需要解决的空白或矛盾
- [ ] 从方法论的成功与失败中学习
- [ ] 确定适当的结果测量指标
- [ ] 确定该领域的典型效应量

## 假设提出

### 假设是否可检验？
- [ ] 做出具体、可量化的预测
- [ ] 变量具有操作性定义
- [ ] 指明预期关系的方向/性质
- [ ] 能够被潜在的观察结果所证伪

### 假设类型
- [ ] **零假设（H₀）：** 不存在效应/关系
- [ ] **备择假设（H₁）：** 存在效应/关系
- [ ] **方向性 vs. 非方向性：** 单尾检验 vs. 双尾检验

## 研究设计选择

### 哪种研究类型合适？

**实验性（干预性）研究：**
- [ ] **随机对照试验（RCT）：** 因果关系的金标准
- [ ] **准实验设计：** 非随机分组但进行操纵
- [ ] **被试内设计：** 同一组被试参与所有条件
- [ ] **被试间设计：** 不同被试参与不同条件
- [ ] **析因设计：** 多个自变量
- [ ] **交叉设计：** 被试按顺序接受多种干预

**观察性研究：**
- [ ] **队列研究：** 随时间追踪群体
- [ ] **病例对照研究：** 比较有/无结局的个体
- [ ] **横断面研究：** 单一时间点的快照
- [ ] **生态学研究：** 群体水平数据

**考虑因素：**
- [ ] 能否随机分配被试？
- [ ] 能否操纵自变量？
- [ ] 结局是罕见（倾向病例对照）还是常见？
- [ ] 是否需要确定时间顺序？
- [ ] 在伦理和实际约束下何种设计可行？

## 变量

### 自变量（操纵/预测变量）
- [ ] 明确定义并操作化
- [ ] 选择适当的水平/类别
- [ ] 操纵足以检验假设
- [ ] 计划操纵检查（如适用）

### 因变量（结局/反应）
- [ ] 直接测量目标构念
- [ ] 经过验证且可靠的测量
- [ ] 灵敏度足以检测预期效应
- [ ] 适合计划的统计分析
- [ ] 明确指定主要结局

### 控制变量
- [ ] **识别混杂变量：**
  - 同时影响自变量和因变量的变量
  - 研究结果的替代解释
- [ ] **控制策略：**
  - 随机化
  - 匹配
  - 分层
  - 统计调整
  - 限制（纳入/排除标准）
  - 盲法

### 额外变量
- [ ] 识别潜在的噪声来源
- [ ] 标准化程序以最小化影响
- [ ] 控制环境因素
- [ ] 标准化时间、地点、设备

## 抽样

### 总体定义
- [ ] **目标总体：** 希望推广至的群体
- [ ] **可及总体：** 实际可以从中抽样的群体
- [ ] **样本：** 实际参与的个体
- [ ] 记录这些之间的差异

### 抽样方法
- [ ] **概率抽样（优先用于可推广性）：**
  - 简单随机抽样
  - 分层抽样
  - 整群抽样
  - 系统抽样
- [ ] **非概率抽样（常见但限制可推广性）：**
  - 便利抽样
  - 目的性抽样
  - 滚雪球抽样
  - 配额抽样

### 样本量
- [ ] **进行先验功效分析**
  - 预期效应量（来自文献或预试验）
  - 期望功效（通常为 .80 或 .90）
  - 显著性水平（通常为 .05）
  - 将使用的统计检验
- [ ] 考虑预期的流失/退出率
- [ ] 足以支持计划的亚组分析
- [ ] 承认实际约束

### 纳入/排除标准
- [ ] 明确定义并有充分理由
- [ ] 不过度限制（限制可推广性）
- [ ] 基于理论或实际考量
- [ ] 解决伦理问题
- [ ] 记录并一致应用

## 盲法与随机化

### 随机化
- [ ] **随机化的对象：**
  - 被试分配到不同条件
  - 条件顺序（被试内设计）
  - 呈现的刺激/项目
- [ ] **随机化方法：**
  - 计算机生成的随机数
  - 随机数表
  - 掷硬币（适用于极小规模研究）
- [ ] **分配隐藏：**
  - 招募前生成分配序列
  - 入组后才揭示分配
  - 按顺序编号的密封信封（如需）
- [ ] **分层随机化：**
  - 在各组间平衡重要变量
  - 区组随机化以确保各组规模相等
- [ ] **检验随机化效果：**
  - 比较各组基线特征
  - 报告任何显著差异

### 盲法
- [ ] **单盲：** 被试不知道分组情况
- [ ] **双盲：** 被试和研究者均不知道
- [ ] **三盲：** 被试、研究者和数据分析者均不知道
- [ ] **盲法可行性：**
  - 是否可能实现真正的盲法？
  - 是否需要安慰剂/假干预对照？
  - 干预措施外观是否一致？
- [ ] **盲法检验：**
  - 评估盲法是否得以维持
  - 询问被试/研究者猜测分组情况

## 对照组与条件设置

### 使用何种对照类型？
- [ ] **无治疗对照：** 观察条件的自然发展
- [ ] **安慰剂对照：** 惰性治疗用于比较
- [ ] **阳性对照：** 与标准治疗比较
- [ ] **等待名单对照：** 延迟治疗
- [ ] **注意力对照：** 匹配接触时间但不含活性成分

### 多条件设计
- [ ] 多因素析因设计
- [ ] 剂量-反应关系评估
- [ ] 通过成分分析检验机制

## 程序

### 方案制定
- [ ] **详细书面方案：**
  - 分步骤程序
  - 标准化指导语脚本
  - 处理问题的决策规则
  - 数据收集表格
- [ ] 正式研究前进行预试验
- [ ] 工作人员经过标准培训
- [ ] 计划依从性监测

### 标准化
- [ ] 对所有被试使用相同指导语
- [ ] 使用相同设备和材料
- [ ] 尽可能在相同环境/场所进行
- [ ] 相同的评估时间
- [ ] 记录偏离方案的情况

### 数据收集
- [ ] **收集时间：**
  - 基线测量
  - 干预后
  - 随访时间点
- [ ] **收集人员：**
  - 经过培训的研究人员
  - 尽可能采用盲法
  - 建立评分者间信度
- [ ] **收集方式：**
  - 有效、可靠的测量工具
  - 标准化施测
  - 尽可能采用多种方法（三角验证）

## 测量

### 效度
- [ ] **表面效度：** 看起来在测量目标构念
- [ ] **内容效度：** 涵盖构念的所有方面
- [ ] **效标效度：** 与金标准相关
  - 同时效度
  - 预测效度
- [ ] **构念效度：** 测量理论构念
  - 收敛效度（与相关测量相关）
  - 区分效度（与不相关测量不相关）

### 信度
- [ ] **重测信度：** 随时间保持一致
- [ ] **内部一致性：** 各条目测量同一构念（Cronbach's α）
- [ ] **评分者间信度：** 评分者之间的一致性（Cohen's κ, ICC）
- [ ] **复本信度：** 替代版本的一致性

### 测量考量
- [ ] 尽可能优先使用客观测量
- [ ] 有验证工具时优先使用
- [ ] 关键构念采用多重测量
- [ ] 考虑对变化的敏感性
- [ ] 避免地板/天花板效应
- [ ] 反应格式适当
- [ ] 回忆周期适当
- [ ] 考虑文化适宜性

## 偏倚最小化

### 选择偏倚
- [ ] 尽可能采用随机抽样
- [ ] 明确定义资格标准
- [ ] 记录拒绝参与者及其原因
- [ ] 最小化自我选择

### 实施偏倚
- [ ] 标准化方案
- [ ] 干预提供者采用盲法
- [ ] 监测方案依从性
- [ ] 记录偏离情况

### 检测偏倚
- [ ] 结局评估者采用盲法
- [ ] 尽可能使用客观测量
- [ ] 标准化评估程序
- [ ] 多名评分者并进行信度检验

### 失访偏倚
- [ ] 最小化退出的策略
- [ ] 追踪退出原因
- [ ] 比较退出者与完成者
- [ ] 计划意向性分析

### 报告偏倚
- [ ] 预注册研究和分析计划
- [ ] 指定主要 vs. 次要结局
- [ ] 承诺报告所有结局
- [ ] 区分计划性分析与探索性分析

## 数据管理

### 数据收集
- [ ] 设计并测试数据收集表格
- [ ] REDCap、Qualtrics 或类似平台
- [ ] 范围检查和验证规则
- [ ] 定期备份
- [ ] 安全存储（如需符合 HIPAA/GDPR）

### 数据质量
- [ ] 实时数据验证
- [ ] 定期质量检查
- [ ] 监测缺失数据模式
- [ ] 识别并调查异常值
- [ ] 记录方案偏离

### 数据安全
- [ ] 去标识化程序
- [ ] 访问控制
- [ ] 审计追踪
- [ ] 符合法规要求（IRB、HIPAA、GDPR）

## 统计分析规划

### 分析计划（数据收集前预先指定）
- [ ] **主要分析：**
  - 指定统计检验
  - 明确陈述假设
  - 设定显著性水平（通常 α = .05）
  - 单尾或双尾
- [ ] **次要分析：**
  - 明确标记为次要
  - 探索性分析如实标注
- [ ] **多重比较：**
  - 指定调整方法（如需）
  - 主要结局防止I类错误膨胀

### 假设条件
- [ ] 识别统计检验的假设条件
- [ ] 计划检验假设条件
- [ ] 备用的非参数替代方案
- [ ] 考虑数据转换选项

### 缺失数据
- [ ] 预估缺失程度
- [ ] 缺失数据机制（MCAR、MAR、MNAR）
- [ ] 处理策略：
  - 完整案例分析
  - 多重插补
  - 最大似然法
- [ ] 计划敏感性分析

### 效应量
- [ ] 确定适当的效应量指标
- [ ] 将与 p 值一同报告
- [ ] 计划置信区间

### 统计软件
- [ ] 选择软件（R、SPSS、Stata、Python 等）
- [ ] 记录版本
- [ ] 提前准备分析脚本
- [ ] 将公开可用（开放科学）

## 伦理考量

### 伦理审批
- [ ] 获得 IRB/伦理委员会批准
- [ ] 如适用，注册研究（ClinicalTrials.gov 等）
- [ ] 方案遵循《赫尔辛基宣言》或同等标准

### 知情同意
- [ ] 自愿参与
- [ ] 通俗易懂的解释
- [ ] 披露风险和获益
- [ ] 有权无惩罚退出
- [ ] 说明隐私保护措施
- [ ] 披露补偿

### 风险-获益分析
- [ ] 潜在获益大于风险
- [ ] 风险最小化
- [ ] 保护弱势群体
- [ ] 数据安全监测（高风险研究）

### 保密性
- [ ] 数据去标识化
- [ ] 安全存储
- [ ] 限制访问
- [ ] 报告不允许重新识别个体

## 效度威胁

### 内部效度（因果关系）
- [ ] **历史事件：** 测量之间的外部事件
- [ ] **成熟效应：** 被试随时间的变化
- [ ] **测试效应：** 重复测量的影响
- [ ] **工具变化：** 测量随时间的变化
- [ ] **均值回归：** 极端分数变得不那么极端
- [ ] **选择效应：** 各组基线不同
- [ ] **流失效应：** 差异性退出
- [ ] **扩散效应：** 对照组接受了干预成分

### 外部效度（可推广性）
- [ ] 样本代表总体
- [ ] 环境真实/自然
- [ ] 干预符合现实世界的实施情况
- [ ] 结局测量具有生态效度
- [ ] 时间框架适当

### 构念效度（测量）
- [ ] 测量确实触及预期构念
- [ ] 操作与理论定义一致
- [ ] 构念之间无混淆
- [ ] 构念覆盖充分

### 统计结论效度
- [ ] 统计功效充足
- [ ] 满足假设条件
- [ ] 使用适当的检验
- [ ] α 水平适当
- [ ] 处理多重比较问题

## 报告与透明度

### 预注册
- [ ] 研究预注册（OSF、ClinicalTrials.gov、AsPredicted）
- [ ] 先验陈述假设
- [ ] 记录分析计划
- [ ] 区分验证性分析与探索性分析

### 报告指南
- [ ] **随机对照试验：** CONSORT 清单
- [ ] **观察性研究：** STROBE 清单
- [ ] **系统综述：** PRISMA 清单
- [ ] **诊断研究：** STARD 清单
- [ ] **质性研究：** COREQ 清单
- [ ] **病例报告：** CARE 指南

### 透明度
- [ ] 报告所有测量
- [ ] 披露所有操纵
- [ ] 解释样本量确定方法
- [ ] 报告排除标准和数量
- [ ] 记录流失情况
- [ ] 注明偏离方案之处
- [ ] 披露利益冲突

### 开放科学
- [ ] 计划数据共享（伦理允许时）
- [ ] 共享分析代码
- [ ] 提供研究材料
- [ ] 发布预印本
- [ ] 尽可能开放获取发表

## 研究后考量

### 数据分析
- [ ] 遵循预注册计划
- [ ] 明确标注偏离和探索性分析
- [ ] 检验假设条件
- [ ] 报告所有结局
- [ ] 报告效应量和置信区间，而非仅 p 值

### 结果解释
- [ ] 结论有数据支持
- [ ] 承认局限性
- [ ] 考虑替代解释
- [ ] 讨论可推广性
- [ ] 讨论临床/实际意义

### 成果传播
- [ ] 无论结果如何均发表（减少发表偏倚）
- [ ] 在学术会议报告
- [ ] 适当向被试分享结果
- [ ] 与相关利益相关者沟通
- [ ] 提供通俗语言摘要

### 后续步骤
- [ ] 是否需要重复验证？
- [ ] 确定后续研究
- [ ] 计划机制研究
- [ ] 考虑临床应用

## 需避免的常见陷阱

- [ ] 无功效分析 → 研究功效不足
- [ ] 看到数据后才形成假设（HARKing）
- [ ] 可行时未采用盲法 → 偏倚
- [ ] P 值操纵（数据挖掘、可选停止）
- [ ] 多重检验未校正 → 假阳性
- [ ] 对照组不充分
- [ ] 未处理混杂因素
- [ ] 测量工具未经验证
- [ ] 高流失率未处理
- [ ] 选择性报告结果
- [ ] 从相关数据得出因果结论
- [ ] 忽略统计检验的假设条件
- [ ] 未预注册导致文献偏倚
- [ ] 未披露利益冲突

## 开始前的最终检查

- [ ] 研究问题清晰且重要
- [ ] 假设可检验且具体
- [ ] 研究设计适当
- [ ] 样本量充足（功效分析）
- [ ] 测量工具有效且可靠
- [ ] 混杂因素得到控制
- [ ] 实施随机化和盲法
- [ ] 数据收集标准化
- [ ] 分析计划预先指定
- [ ] 获得伦理批准
- [ ] 研究已预注册
- [ ] 资源充足
- [ ] 团队经过培训
- [ ] 方案有文档记录
- [ ] 针对问题有备用计划

## 请记住

**良好的实验设计在于：**
- 提出清晰的问题
- 最小化偏倚
- 最大化效度
- 进行恰当的推断
- 保持透明
- 确保可复现性

**思考这些问题的最佳时机是在收集数据之前，而非之后。**
