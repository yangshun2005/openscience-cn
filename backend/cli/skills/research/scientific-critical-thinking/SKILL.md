# 科学批判性思维

## 概述

批判性思维是评估科学严谨性的系统性过程。使用 GRADE 和 Cochrane ROB 框架评估方法论、实验设计、统计有效性、偏倚、混杂因素和证据质量。应用此技能对科学主张进行批判性分析。

## 何时使用此技能

在以下情况下应使用此技能：
- 评估研究方法和实验设计
- 评估统计有效性和证据质量
- 识别研究中的偏倚和混杂因素
- 审查科学主张和结论
- 进行系统评价或荟萃分析
- 应用 GRADE 或 Cochrane 偏倚风险评估
- 对研究论文进行批判性分析

## 核心能力

### 1. 方法论批判

评估研究方法论的严谨性、有效性和潜在缺陷。

**应用场景：**
- 审查研究论文
- 评估实验设计
- 评估研究方案
- 规划新研究

**评估框架：**

1. **研究设计评估**
   - 设计是否适合研究问题？
   - 设计能否支持所提出的因果主张？
   - 比较组是否适当且充分？
   - 考虑实验性、准实验性或观察性设计是否合理

2. **有效性分析**
   - **内部有效性：** 我们能相信因果推断吗？
     - 检查随机化质量
     - 评估混杂控制
     - 评估选择偏倚
     - 审查损耗/退出模式
   - **外部有效性：** 结果能否推广？
     - 评估样本代表性
     - 考虑环境的生态效度
     - 评估条件是否与目标应用匹配
   - **构念效度：** 测量是否捕捉到预期的构念？
     - 审查测量验证
     - 检查操作性定义
     - 评估测量是直接的还是代理的
   - **统计结论效度：** 统计推断是否合理？
     - 验证足够的检验力/样本量
     - 检查假设符合性
     - 评估检验的适当性

3. **对照和盲法**
   - 随机化是否正确实施（序列生成、分配隐藏）？
   - 盲法是否可行并实施（参与者、提供者、评估者）？
   - 对照条件是否适当（安慰剂、主动对照、无治疗）？
   - 实施偏倚或检测偏倚是否会影响结果？

4. **测量质量**
   - 工具是否经过验证且可靠？
   - 测量在可能时是否客观，或在主观时是否承认局限性？
   - 结果评估是否标准化？
   - 是否使用多种测量来三角验证发现？

**参考：** 参见 `references/scientific_method.md` 了解详细原则，参见 `references/experimental_design.md` 获取全面设计检查清单。

### 2. 偏倚检测

识别和评估可能扭曲发现的潜在偏倚来源。

**应用场景：**
- 审查已发表的研究
- 设计新研究
- 解释相互矛盾的证据
- 评估研究质量

**系统性偏倚审查：**

1. **认知偏倚（研究者）**
   - **确认偏倚：** 是否只强调支持性发现？
   - **HARKing（事后假设）：** 假设是先验陈述还是看到结果后形成的？
   - **发表偏倚：** 阴性结果是否在文献中缺失？
   - **选择性报告：** 证据是否被选择性报告？
   - 检查预注册和分析计划透明度

2. **选择偏倚**
   - **抽样偏倚：** 样本是否代表目标人群？
   - **志愿者偏倚：** 参与者是否以系统方式自我选择？
   - **损耗偏倚：** 各组间的退出率是否存在差异？
   - **幸存者偏倚：** 样本中是否只看到“幸存者”？
   - 检查参与者流程图并比较基线特征

3. **测量偏倚**
   - **观察者偏倚：** 期望是否会影响观察？
   - **回忆偏倚：** 回顾性报告是否系统性地不准确？
   - **社会期望偏倚：** 回答是否偏向可接受性？
   - **工具偏倚：** 测量工具是否系统性出错？
   - 评估盲法、验证和测量的客观性

4. **分析偏倚**
   - **P-hacking（数据挖掘）：** 是否进行了多次分析直到出现显著性？
   - **结果转换：** 非显著结果是否被替换为显著结果？
   - **选择性报告：** 是否报告了所有计划的分析？
   - **亚组钓鱼：** 是否在没有校正的情况下进行亚组分析？
   - 检查研究注册并比较已发表的结果

5. **混杂因素**
   - 哪些变量可能同时影响暴露和结果？
   - 混杂因素是否被测量和控制（统计上或通过设计）？
   - 未测量的混杂因素能否解释发现？
   - 是否存在合理的替代解释？

**参考：** 参见 `references/common_biases.md` 获取全面的偏倚分类及检测和缓解策略。

### 3. 统计分析评估

批判性评估统计方法、解释和报告。

**应用场景：**
- 审查定量研究
- 评估数据驱动的主张
- 评估临床试验结果
- 审查荟萃分析

**统计审查检查清单：**

1. **样本量和检验力**
   - 是否进行了先验检验力分析？
   - 样本是否足以检测有意义的效应？
   - 研究是否检验力不足（常见问题）？
   - 小样本的显著结果是否引发效应量膨胀的警示？

2. **统计检验**
   - 检验是否适合数据类型和分布？
   - 检验假设是否被检查并满足？
   - 参数检验是否合理，还是应使用非参数替代方法？
   - 分析是否与研究设计匹配（例如，配对 vs. 独立）？

3. **多重比较**
   - 是否检验了多个假设？
   - 是否应用了校正（Bonferroni、FDR 或其他）？
   - 主要结果是否与次要/探索性结果区分？
   - 发现是否可能是多重检验导致的假阳性？

4. **P 值解释**
   - P 值是否被正确解释（假设零假设为真时数据的概率）？
   - 非显著性是否被错误解释为“无效应”？
   - 统计显著性是否与实际重要性混淆？
   - 是否报告精确 P 值，还是仅报告“p < .05”？
   - 是否在略低于 .05 处存在可疑聚集？

5. **效应量和置信区间**
   - 是否在显著性之外还报告了效应量？
   - 是否提供置信区间以显示精度？
   - 效应量在实际意义上是否有意义？
   - 标准化效应量是否结合领域特定背景进行解释？

6. **缺失数据**
   - 有多少数据缺失？
   - 是否考虑了缺失数据机制（MCAR、MAR、MNAR）？
   - 如何处理缺失数据（删除、插补、最大似然）？
   - 缺失数据是否会使结果产生偏倚？

7. **回归和建模**
   - 模型是否过拟合（预测变量过多，无交叉验证）？
   - 是否在数据范围之外进行预测（外推）？
   - 多重共线性问题是否得到解决？
   - 模型假设是否被检查？

8. **常见陷阱**
   - 将相关性视为因果关系
   - 忽略均值回归
   - 忽视基础比率
   - 德州神枪手谬误（在噪声中寻找模式）
   - 辛普森悖论（亚组混杂）

**参考：** 参见 `references/statistical_pitfalls.md` 获取详细陷阱和正确实践。

### 4. 证据质量评估

系统评估证据的强度和质量的系统性过程。

**应用场景：**
- 权衡决策证据
- 进行文献综述
- 比较相互矛盾的发现
- 确定结论的信心

**证据评估框架：**

1. **研究设计层级**
   - 系统评价/荟萃分析（干预效果最高）
   - 随机对照试验
   - 队列研究
   - 病例对照研究
   - 横断面研究
   - 病例系列/报告
   - 专家意见（最低）

   **重要提示：** 更高级别的设计并不总是质量更好。设计良好的观察性研究可能比执行不佳的 RCT 更强。

2. **设计类型内的质量**
   - 偏倚风险评估（使用适当工具：Cochrane ROB、Newcastle-Ottawa 等）
   - 方法论严谨性
   - 透明度和报告完整性
   - 利益冲突

3. **GRADE 考虑因素（如适用）**
   - 从设计类型开始（RCT = 高，观察性 = 低）
   - **降级因素：**
     - 偏倚风险
     - 研究间不一致性
     - 间接性（错误人群/干预/结果）
     - 不精确性（宽置信区间、小样本）
     - 发表偏倚
   - **升级因素：**
     - 大效应量
     - 剂量-反应关系
     - 混杂因素会减少（而非增加）效应

4. **证据汇聚**
   - **更强当：**
     - 多个独立重复
     - 不同的研究团队和场景
     - 不同方法汇聚于相同结论
     - 机制性和经验性证据一致
   - **更弱当：**
     - 单一研究或研究团队
     - 文献中存在矛盾发现
     - 发表偏倚明显
     - 无重复尝试

5. **情境因素**
   - 生物学/理论合理性
   - 与既有知识的一致性
   - 时间性（原因先于结果）
   - 关系的特异性
   - 关联强度

**参考：** 参见 `references/evidence_hierarchy.md` 获取详细层级、GRADE 系统和质量评估工具。

### 5. 逻辑谬误识别

检测并命名科学论证和主张中的逻辑错误。

**应用场景：**
- 评估科学主张
- 审查讨论/结论部分
- 评估科普传播
- 识别有缺陷的推理

**科学中常见的谬误：**

1. **因果谬误**
   - **事后归因谬误：** “B 在 A 之后，所以 A 导致 B”
   - **相关性 = 因果性：** 混淆关联与因果关系
   - **反向因果：** 将结果误认为原因
   - **单一原因谬误：** 将复杂结果归因于单一因素

2. **概括谬误**
   - **轻率概括：** 从小样本得出宽泛结论
   - **轶事谬误：** 将个人故事作为证据
   - **选择性采摘：** 只选择支持性证据
   - **生态谬误：** 将群体模式应用于个体

3. **权威和来源谬误**
   - **诉诸权威：** “专家说的，所以是真的”（无证据）
   - **人身攻击：** 攻击人而非论点
   - **起源谬误：** 根据来源而非价值判断
   - **诉诸自然：** “自然的 = 好的/安全的”

4. **统计谬误**
   - **忽视基础比率：** 忽略先验概率
   - **德州神枪手：** 在随机数据中寻找模式
   - **多重比较：** 未对多重检验进行校正
   - **检察官谬误：** 混淆 P(E|H) 与 P(H|E)

5. **结构谬误**
   - **虚假二分法：** “要么 A 要么 B”，而存在更多选项
   - **移动球门柱：** 在标准满足后改变证据标准
   - **循环论证：** 循环推理
   - **稻草人谬误：** 歪曲论点以攻击它们

6. **科学特定谬误**
   - **伽利略赌注：** “他们嘲笑伽利略，所以我的边缘想法是正确的”
   - **诉诸无知：** “未被证明为假，所以为真”
   - **涅槃谬误：** 拒绝不完美的解决方案
   - **不可证伪性：** 提出无法检验的主张

**识别谬误时：**
- 指出具体的谬误名称
- 解释推理为何有缺陷
- 确定有效推断需要什么证据
- 注意谬误推理并不证明结论为假——只是这个论证不支持它

**参考：** 参见 `references/logical_fallacies.md` 获取全面的谬误目录及示例和检测策略。

### 6. 研究设计指导

为规划严谨研究提供建设性指导。

**应用场景：**
- 帮助设计新实验
- 规划研究项目
- 审查研究提案
- 改进研究方案

**设计过程：**

1. **研究问题细化**
   - 确保问题具体、可回答且可证伪
   - 验证其是否解决文献中的空白或矛盾
   - 确认可行性（资源、伦理、时间）
   - 操作性定义变量

2. **设计选择**
   - 将设计匹配到问题（因果 → 实验性；关联 → 观察性）
   - 考虑可行性和伦理约束
   - 选择被试间、被试内或混合设计
   - 如果测试多个因素，规划因子设计

3. **偏倚最小化策略**
   - 尽可能实施随机化
   - 在所有可行层面规划盲法（参与者、提供者、评估者）
   - 识别并规划控制混杂（随机化、匹配、分层、统计调整）
   - 标准化所有程序
   - 规划以最小化损耗

4. **样本规划**
   - 进行先验检验力分析（指定预期效应、期望检验力、α）
   - 在样本量中考虑损耗
   - 定义明确的纳入/排除标准
   - 考虑招募策略和可行性
   - 规划样本代表性

5. **测量策略**
   - 选择经过验证、可靠的仪器
   - 尽可能使用客观测量
   - 规划关键构念的多重测量（三角验证）
   - 确保测量对预期变化敏感
   - 建立评分者间信度程序

6. **分析规划**
   - 预先指定所有假设和分析
   - 明确指定主要结果
   - 规划统计检验并检查假设
   - 指定如何处理缺失数据
   - 规划报告效应量和置信区间
   - 考虑多重比较校正

7. **透明度和严谨性**
   - 预注册研究和分析计划
   - 使用报告指南（CONSORT、STROBE、PRISMA）
   - 规划报告所有结果，而不仅仅是显著结果
   - 区分验证性分析与探索性分析
   - 承诺数据和代码共享

**参考：** 参见 `references/experimental_design.md` 获取涵盖从问题到传播所有阶段的全面设计检查清单。

### 7. 主张评估

系统评估科学主张的有效性和支持度。

**应用场景：**
- 评估论文中的结论
- 评估媒体对研究的报道
- 审查摘要或引言中的主张
- 检查数据是否支持结论

**主张评估过程：**

1. **识别主张**
   - 具体主张是什么？
   - 是因果主张、关联主张还是描述性主张？
   - 主张的强度如何（已证明、可能、建议、可能）？

2. **评估证据**
   - 提供了什么证据？
   - 证据是直接的还是间接的？
   - 证据是否足以支持主张的强度？
   - 替代解释是否被排除？

3. **检查逻辑连接**
   - 结论是否从数据中得出？
   - 是否存在逻辑跳跃？
   - 是否使用相关数据支持因果主张？
   - 局限性是否被承认？

4. **评估相称性**
   - 信心是否与证据强度相称？
   - 是否适当使用模糊性词语？
   - 局限性是否被淡化？
   - 推测是否被明确标注？

5. **检查过度概括**
   - 主张是否超出所研究样本的范围？
   - 人群限制是否被承认？
   - 情境依赖性是否被认识？
   - 是否包含关于概括的警告？

6. **警示信号**
   - 从相关研究中使用因果语言
   - “证明”或绝对确定性
   - 选择性引用
   - 忽略矛盾证据
   - 轻视局限性
   - 超出数据的外推

**提供具体反馈：**
- 引用有问题的主张
- 解释支持它需要什么证据
- 如有必要，建议适当的模糊性语言
- 区分数据（发现了什么）与解释（这意味着什么）

## 应用指南

### 一般方法

1. **保持建设性**
   - 识别优点和缺点
   - 建议改进而非仅批评
   - 区分致命缺陷和次要限制
   - 认识到所有研究都有局限性

2. **保持具体**

   - 引用有问题的陈述
   - 提供问题的具体示例
