# 科学假设生成

## 概述

假设生成是一个系统性的过程，用于提出可检验的解释。基于观察提出有证据支持的假设，设计实验，探索竞争性解释，并发展预测。在跨学科的科学探究中应用此技能。

## 何时使用此技能

在以下情况下应使用此技能：
- 从观察或初步数据中提出假设
- 设计实验以检验科学问题
- 探索对现象的不同解释
- 为研究制定可检验的预测
- 进行基于文献的假设生成
- 规划跨科学领域的机制研究

## 使用科学示意图进行视觉增强

2. 对于综合性报告，建议使用 2-3 张图表（机制路径图、实验设计流程图、预测决策树）

AI 将自动：

- 将输出保存到 figures/ 目录

**何时添加示意图：**

## 工作流程

遵循以下系统化流程来生成稳健的科学假设：

### 1. 理解现象

首先明确需要解释的观察、问题或现象：

- 确定需要解释的核心观察或模式
- 定义现象的范围和边界
- 注意任何限制条件或特定背景
- 澄清已知与不确定的内容
- 确定相关的科学领域

### 2. 进行全面的文献检索

检索现有科学文献，使假设基于当前证据。同时使用 PubMed（针对生物医学主题）和通用网络搜索（针对更广泛的科学领域）：

**对于生物医学主题：**
- 使用 WebFetch 访问 PubMed URL 以获取相关文献
- 搜索最近的综述、荟萃分析和原始研究
- 寻找相似的现象、相关机制或类似系统

**对于所有科学领域：**
- 使用 WebSearch 查找最近的论文、预印本和综述
- 搜索已建立的理论、机制或框架
- 识别当前理解中的空白

**检索策略：**
- 从广泛搜索开始以了解整体情况
- 缩小范围至特定机制、路径或理论
- 寻找矛盾的发现或未解决的争论
- 查阅 `references/literature_search_strategies.md` 获取详细检索技术

### 3. 综合现有证据

分析并整合文献检索的发现：

- 总结当前对现象的理解
- 识别可能适用的已建立机制或理论
- 记录冲突的证据或替代观点
- 识别空白、局限性或未解答的问题
- 从相关系统或领域寻找类比

### 4. 生成竞争性假设

提出 3-5 个能够解释该现象的独特假设。每个假设应：

- 提供机制性解释（不仅仅是描述）
- 与其他假设可区分
- 基于文献综合的证据
- 考虑不同层面的解释（分子、细胞、系统、群体等）

**生成假设的策略：**
- 应用来自类似系统的已知机制
- 考虑多种因果路径
- 探索不同尺度的解释
- 质疑现有解释中的假设
- 以新颖方式组合机制

### 5. 评估假设质量

根据 `references/hypothesis_quality_criteria.md` 中建立的质量标准评估每个假设：

**可检验性：** 该假设能否被实证检验？
**可证伪性：** 哪些观察结果会反驳它？
**简约性：** 它是否符合证据的最简单解释？
**解释力：** 它能在多大程度上解释该现象？
**范围：** 它涵盖了多少观察结果？
**一致性：** 它是否与既定原则一致？
**新颖性：** 它是否提供了超越现有解释的新见解？

明确记录每个假设的优势和劣势。

### 6. 设计实验检验

对于每个可行的假设，提出具体的实验或研究来检验它。查阅 `references/experimental_design_patterns.md` 获取常用方法：

**实验设计要素：**
- 需要测量或观察什么？
- 需要哪些比较或对照？
- 将使用哪些方法或技术？
- 合适的样本量或统计方法是什么？
- 潜在的混杂因素是什么以及如何解决？

**考虑多种方法：**
- 实验室实验（体外、体内、计算）
- 观察性研究（横断面、纵向、病例对照）
- 临床试验（如适用）
- 自然实验或准实验设计

### 7. 制定可检验的预测

对于每个假设，生成具体的、定量的预测：

- 说明如果假设正确，应观察到什么
- 尽可能指定效应的预期方向和大小
- 确定预测应成立的条件
- 区分竞争性假设之间的预测
- 指出能够证伪该假设的预测

### 8. 呈现结构化输出

使用 `assets/hypothesis_report_template.tex` 中的模板生成专业的 LaTeX 文档。报告应格式良好，使用彩色框进行视觉组织，并分为简洁的正文和全面的附录。

**文档结构：**

**正文（最多 4 页）：**
1. **执行摘要** - 在摘要框中简要概述（0.5-1 页）
2. **竞争性假设** - 每个假设放在其自己的彩色框中，包含简要的机制解释和关键证据（3-5 个假设占 2-2.5 页）
   - **重要提示：** 在每个假设框前使用 `\newpage` 以防止内容溢出
   - 每个框最多不超过 0.6 页
3. **可检验的预测** - 关键预测放在琥珀色框中（0.5-1 页）
4. **关键比较** - 优先比较框（0.5-1 页）

保持正文高度简洁——只包含最关键的信息。所有细节放入附录。

**分页策略：**
- 始终在假设框前使用 `\newpage` 以确保它们从新页面开始
- 这可以防止内容溢出页面边界
- LaTeX 框（tcolorbox）不会自动跨页

**附录（全面、详细）：**
- **附录 A：** 包含大量引用的全面文献综述
- **附录 B：** 包含完整协议的详细实验设计
- **附录 C：** 质量评估表和详细评估
- **附录 D：** 补充证据和类似系统

**彩色框使用：**

使用 `hypothesis_generation.sty` 中的自定义框环境：

- `hypothesisbox1` 至 `hypothesisbox5` - 用于每个竞争性假设（蓝色、绿色、紫色、青色、橙色）
- `predictionbox` - 用于可检验的预测（琥珀色）
- `comparisonbox` - 用于关键比较（钢灰色）
- `evidencebox` - 用于突出支持性证据（浅蓝色）
- `summarybox` - 用于执行摘要（蓝色）

**每个假设框应包含（保持简洁以满足 4 页限制）：**
- **机制解释：** 1-2 个简短段落（最多 6-10 句话），解释如何及为何
- **关键支持证据：** 2-3 个带引用的要点（仅限最重要的证据）
- **核心假设：** 1-2 个关键假设

所有详细解释、额外证据和全面讨论应放入附录。

**关键溢出预防：**
- 在每个假设框前插入 `\newpage` 以使其从新页面开始
- 保持每个完整的假设框不超过 0.6 页（约 15-20 行内容）
- 如果内容超出此限制，将额外细节移至附录 A
- 绝不允许框溢出页面边界——这会产生不可读的 PDF

**引用要求：**

力求广泛引用以支持所有主张：
- **正文：** 仅引用 10-15 个最关键证据的文献（保持简洁以满足 4 页限制）
- **附录 A：** 40-70+ 条涵盖所有相关文献的全面引用
- **总目标：** 参考文献列表中 50+ 条引用

正文引用应有选择性——只引用最关键的论文。所有全面的引用和详细的文献讨论应放入附录。使用 `\citep{author2023}` 进行括号引用。

**LaTeX 编译：**

模板需要 XeLaTeX 或 LuaLaTeX 才能正确渲染：

```bash
xelatex hypothesis_report.tex
bibtex hypothesis_report
xelatex hypothesis_report.tex
xelatex hypothesis_report.tex
```

**所需包：** `hypothesis_generation.sty` 样式包必须位于同一目录或 LaTeX 路径中。它需要：tcolorbox、xcolor、fontspec、fancyhdr、titlesec、enumitem、booktabs、natbib。

**页面溢出预防：**

为防止内容溢出页面，请遵循以下关键准则：

1. **监控框内容长度：** 每个假设框应能舒适地放在单页上。如果内容超过约 0.7 页，则可能溢出。

2. **使用战略性分页符：** 在包含大量内容的框前插入 `\newpage`：
   ```latex
   \newpage
   \begin{hypothesisbox1}[假设 1：标题]
   % 此处为长内容
   \end{hypothesisbox1}
   ```

3. **保持正文框简洁：** 对于 4 页正文限制：
   - 每个假设框：最多 0.5-0.6 页
   - 机制解释：仅 1-2 个简短段落（最多 6-10 句话）
   - 关键证据：仅 2-3 个要点
   - 核心假设：仅 1-2 项
   - 如果内容较长，将细节移至附录

4. **拆分长内容：** 如果某个假设需要大量解释，可在正文和附录之间拆分：
   - 正文框：简要机制概述 + 2-3 个关键证据点
   - 附录 A：详细机制解释、全面证据、扩展讨论

5. **测试页面边界：** 在每个新框之前，考虑剩余页面空间是否足够。如果剩余空间少于 0.6 页，使用 `\newpage` 使框从新页面开始。

6. **附录页面管理：** 在附录中，在主要部分之间使用 `\newpage` 以避免详细内容区域溢出。

**快速参考：** 参见 `assets/FORMATTING_GUIDE.md` 获取所有框类型、配色方案和常见格式模式的详细示例。

## 质量标准

确保所有生成的假设符合以下标准：

- **基于证据：** 基于现有文献并附有引用
- **可检验：** 包含具体的、可测量的预测
- **机制性：** 解释如何/为何，而不仅仅是是什么
- **全面性：** 考虑替代解释
- **严谨性：** 包含检验预测的实验设计
