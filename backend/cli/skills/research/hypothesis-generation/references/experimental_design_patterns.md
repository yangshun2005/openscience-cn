# 实验设计模式

## 科学假设检验的常用方法

本参考资料提供了跨科学领域设计实验的模式和框架。使用这些模式为生成的假设制定严格的检验方案。

**关于报告结构的说明：** 在生成假设报告时，仅在正文假设框中提及关键实验方法（例如“体内基因敲除研究”或“前瞻性队列设计”）。在**附录B：详细实验设计**中，包含完整的实验方案，包括全部方法、对照、样本量、统计方法、可行性评估和资源需求。

## 设计选择框架

根据以下因素选择实验方法：
- **假设性质：** 机制性、因果性、相关性、描述性
- **研究系统：** 体外、体内、计算、观察性
- **可行性：** 时间、成本、伦理、技术能力
- **所需证据：** 概念验证、因果证明、定量关系

## 实验室实验设计

### 体外实验

**适用场景：** 在受控系统中检验分子、细胞或生化机制。

**常见模式：**

#### 1. 剂量-反应研究
- **目的：** 建立输入与效应之间的定量关系
- **设计：** 测试多个浓度的干预措施
- **关键要素：**
  - 阴性对照（不处理）
  - 阳性对照（已知有效处理）
  - 多个剂量水平（通常5-8个点）
  - 技术重复（每个条件≥3次）
  - 适当的统计分析（曲线拟合、IC50/EC50测定）

**应用示例：**
“为检验化合物X是否抑制酶Y，在0、1、10、100、1000 nM化合物X浓度下测量酶活性，每个剂量设n=3个重复。”

#### 2. 功能获得/缺失研究
- **目的：** 建立特定组分的因果作用
- **设计：** 添加（过表达）或去除（敲除/敲低）特定组分
- **关键要素：**
  - 野生型对照
  - 功能获得条件（过表达、组成性激活）
  - 功能缺失条件（敲除、敲低、抑制）
  - 拯救实验（恢复功能缺失条件下的功能）
  - 测量下游效应

**应用示例：**
“检验蛋白X是否导致表型Y：（1）敲除X并观察表型是否消失，（2）过表达X并观察表型是否增强，（3）通过X的重新表达来拯救敲除表型。”

#### 3. 时间进程研究
- **目的：** 了解时间动态和事件顺序
- **设计：** 在多个时间点测量结果
- **关键要素：**
  - 0时间点基线
  - 早期时间点（捕捉快速变化）
  - 中间时间点
  - 晚期时间点（稳态）
  - 每个时间点有足够的重复

**应用示例：**
“在刺激后0、5、15、30、60、120分钟测量蛋白磷酸化水平，以确定峰值激活时间。”

### 体内实验

**适用场景：** 在完整生物体中检验假设，评估全身性、生理性或行为效应。

**常见模式：**

#### 4. 受试者间设计
- **目的：** 比较接受不同处理的不同组别
- **设计：** 将受试者随机分配到处理组
- **关键要素：**
  - 随机分组
  - 适当的样本量（功效分析）
  - 对照组（载体、假手术或标准治疗）
  - 盲法（单盲或双盲）
  - 各组条件标准化

**应用示例：**
“将每组20只小鼠随机分配到载体对照组或药物治疗组，每周测量肿瘤大小，持续8周，实验人员对分组情况设盲。”

#### 5. 受试者内（重复测量）设计
- **目的：** 每个受试者作为自身对照，减少受试者间变异
- **设计：** 同一受试者在多个条件/时间点进行测量
- **关键要素：**
  - 基线测量
  - 平衡设计（如果可能存在顺序效应）
  - 洗脱期（用于序贯治疗）
  - 适当的重复测量统计方法

**应用示例：**
“在同一参与者的基线、训练干预后以及3个月随访时测量认知表现。”

#### 6. 析因设计
- **目的：** 同时检验多个因素及其交互作用
- **设计：** 交叉多个自变量的所有水平
- **关键要素：**
  - 明确的主效应和交互作用
  - 交互作用检验有足够的统计功效
  - 根据情况选择全因子或部分析因设计

**应用示例：**
“2×2设计，交叉基因型（野生型 vs. 突变型）×处理（载体 vs. 药物），检验药物效应是否依赖于基因型。”

### 计算/建模实验

**适用场景：** 检验关于复杂系统的假设、做出预测，或当物理实验不可行时。

#### 7. 计算机模拟
- **目的：** 对复杂系统建模，检验理论预测
- **设计：** 实现计算模型并改变参数
- **关键要素：**
  - 具有明确假设的清晰定义模型
  - 参数敏感性分析
  - 与已知数据验证
  - 为实验检验生成预测

**应用示例：**
“构建疾病传播的基于智能体的模型，改变传播率和干预时机，将预测与经验流行病学数据进行比较。”

#### 8. 生物信息学/荟萃分析
- **目的：** 利用现有数据集检验假设
- **设计：** 分析大规模数据或汇总多项研究
- **关键要素：**
  - 适当的统计校正（多重检验）
  - 在独立数据集中验证
  - 控制混杂因素和批次效应
  - 明确的纳入/排除标准

**应用示例：**
“检验基因X的表达是否与15个癌症数据集（总计n>5000名患者）中的生存率相关，使用含临床协变量的Cox回归分析。”

## 观察性研究设计

### 当物理操作不可能或不道德时

#### 9. 横断面研究
- **目的：** 在单一时间点检验关联
- **设计：** 在某一时间点测量人群中的感兴趣变量
- **优势：** 快速、廉价，可确定患病率
- **局限性：** 无法确定时间顺序或因果关系
- **关键要素：**
  - 代表性抽样
  - 标准化测量
  - 控制混杂变量
  - 适当的统计分析

**应用示例：**
“调查1000名成年人，检验饮食模式与生物标志物X之间的关联，控制年龄、性别、BMI和体力活动。”

#### 10. 队列研究（前瞻性/纵向）
- **目的：** 建立时间关系及潜在的因果关联
- **设计：** 随时间跟踪一组人群，测量暴露和结局
- **优势：** 可确定时间顺序，计算发病率
- **局限性：** 耗时、昂贵、存在失访
- **关键要素：**
  - 基线暴露评估
  - 按确定间隔随访
  - 尽量减少失访
  - 考虑时变混杂因素

**应用示例：**
“随访5000名最初健康的个体10年，检验基线维生素D水平是否能预测心血管疾病发病率。”

#### 11. 病例对照研究
- **目的：** 通过比较病例与对照来有效研究罕见结局
- **设计：** 确定具有结局的病例，选择匹配的对照，比较暴露情况
- **优势：** 对罕见疾病高效，相对快速
- **局限性：** 回忆偏倚、选择偏倚，无法计算发病率
- **关键要素：**
  - 明确的病例定义
  - 适当的对照选择（匹配或统计调整）
  - 回顾性暴露评估
  - 控制混杂因素

**应用示例：**
“比较200名患有罕见疾病X的患者与400名匹配的无X对照者，检验早年暴露Y在两组间是否存在差异。”

## 临床试验设计

#### 12. 随机对照试验（RCT）
- **目的：** 检验人类干预措施的金标准
- **设计：** 将参与者随机分配到治疗组或对照组
- **关键要素：**
  - 随机化（简单、区组或分层）
  - 分配隐藏
  - 盲法（参与者、提供者、评估者）
  - 意向性分析
  - 预先注册的方案和分析计划

**应用示例：**
“双盲随机对照试验：将300名患者随机分配接受药物X或安慰剂治疗12周，测量主要结局指标——症状改善情况。”

#### 13. 交叉试验
- **目的：** 每位参与者按顺序接受所有治疗
- **设计：** 参与者在不同治疗之间交叉，中间设洗脱期
- **优势：** 减少受试者间变异，所需参与者较少
- **局限性：** 顺序效应，需要可逆条件，周期较长
- **关键要素：**
  - 足够的洗脱期
  - 随机化治疗顺序
  - 残留效应评估

**应用示例：**
“交叉试验：参与者接受治疗A 4周，2周洗脱期，然后接受治疗B 4周（顺序随机化）。”

## 高级设计考虑因素

### 样本量和统计功效

**关键问题：**
- 需要检测多大的效应量才有意义？
- 将使用什么统计检验？
- 适当的α（显著性水平）和β（功效）是多少？
- 测量中预期的变异有多大？

**一般指南：**
- 实验前进行正式的功效分析
- 预实验每组最低n≥10
- 确定性研究目标功效≥80%
- 考虑纵向研究中的潜在失访

### 对照

**对照类型：**
- **阴性对照：** 无干预（基线）
- **阳性对照：** 已知有效的干预（验证系统）
- **载体对照：** 不含活性成分的给药方式
- **假手术对照：** 模拟干预但不含活性成分（手术等）
- **历史对照：** 先前数据（最弱，尽量避免）

### 盲法

**级别：**
- **开放标签：** 不设盲（适用于客观测量）
- **单盲：** 参与者设盲（减少安慰剂效应）
- **双盲：** 参与者和实验人员均设盲（减少评估偏倚）
- **三盲：** 参与者、实验人员和数据分析人员均设盲（最强）

### 重复

**技术重复：** 对同一份样本进行重复测量
- 减少测量误差
- 通常2-3次重复即可

**生物学重复：** 独立样本/受试者
- 处理生物学变异
- 对推广至关重要
- 最低：n≥3，最好每组n≥5-10

**实验重复：** 重复整个实验
- 在不同时间、设备、操作者之间验证发现
- 确认结果的金标准

### 混杂控制

**策略：**
- **随机化：** 将混杂因素均匀分布在各组
- **匹配：** 在不同条件下配对相似受试者
- **区组化：** 按混杂因素分组，然后在区组内随机化
- **统计调整：** 测量混杂因素并在分析中进行调整
- **标准化：** 保持各组条件一致

## 选择适当的设计

**决策树：**

1. **变量能否被操作？**
   - 能 → 实验设计（随机对照试验、实验室实验）
   - 不能 → 观察性设计（队列、病例对照、横断面）

2. **研究系统是什么？**
   - 细胞/分子 → 体外实验
   - 完整生物体 → 体内实验
   - 人类 → 临床试验或观察性研究
   - 复杂系统 → 计算建模

3. **主要目标是什么？**
   - 机制 → 功能获得/缺失、剂量-反应
   - 因果 → 随机对照试验、良好对照的队列研究
   - 关联 → 横断面、病例对照
   - 预测 → 建模、机器学习
   - 时间动态 → 时间进程、纵向研究

4. **有哪些约束条件？**
   - 时间有限 → 横断面、体外实验
   - 预算有限 → 计算、观察性研究
   - 伦理问题 → 观察性研究、体外实验
   - 罕见结局 → 病例对照、荟萃分析

## 整合多种方法

强有力的假设检验通常结合多种设计：

**示例：检验微生物组是否影响认知功能**
1. **观察性研究：** 队列研究显示微生物组组成与认知之间存在关联
2. **动物模型：** 接受微生物组移植的无菌小鼠表现出认知变化
3. **机制研究：** 体外研究显示微生物代谢产物影响神经元功能
4. **临床试验：** 益生菌干预改善认知评分的随机对照试验
5. **计算建模：** 预测哪些微生物组谱应影响认知的模型

**三角验证方法：**
- 每种设计解决不同方面/局限性
- 来自多种方法的汇聚证据增强因果主张的可信度
- 从观察性/体外研究开始，然后推进到明确的因果检验

## 常见陷阱

- 样本量不足（统计功效不足）
- 缺乏适当的对照
- 未考虑混杂变量
- 统计检验不当
- P值操纵或未校正的多重检验
- 涉及主观评估时未设盲
- 未能重复验证发现
- 未预先注册分析计划（临床试验）

## 假设检验的实际应用

在设计实验检验假设时：

1. **将设计与假设细节匹配：** 因果主张需要实验操作；关联可以使用观察性设计
2. **先简单后复杂：** 用简单设计进行预实验，然后增加复杂性
3. **仔细规划对照：** 对照验证系统并隔离特定效应
4. **考虑可行性：** 在理想设计与实际约束之间取得平衡
5. **规划多个实验：** 很少有单一实验能最终检验一个假设
6. **预先指定分析：** 在数据收集前确定统计检验
7. **内置验证：** 独立重复、正交方法、汇聚证据
