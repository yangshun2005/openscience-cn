# 同行评审校准指南

本指南旨在校准AI辅助同行评审，使其符合人类审稿人标准，基于与实际同行评审的实证比较。

## 概述

AI同行评审系统往往比人类审稿人更为严苛。本文档提供校准原则，以确保评审公平、均衡，并与社区标准保持一致。

## 校准指标

在将AI评审与人类评审进行验证时：

| 指标 | 目标 | 典型AI未校准值 |
|--------|--------|------------------------|
| 科学性批评一致性 | 85-90% | 80-85% |
| 评分校准 | 90%以上 | 60-70%（过于严苛） |
| 完整性（规范性） | 90%以上 | 75-80%（遗漏表达问题） |

## 核心校准原则

### 1. 局限性承认奖励

**原则：** 诚实承认局限性的作者不应因这些局限性而受到重罚。

**校准规则：**
- 若作者明确承认某项局限性 → 处罚降低50%
- 对已承认的局限性，扣分不得超过1分
- 在总结中肯定其诚实的自我评估

**示例：**
> **论文陈述：** “我们工作的一个局限性是仅使用了合成基准测试。”
>
> **未校准回复：** “严重缺陷：缺乏真实世界验证，使所有主张失去依据。” [-3分]
>
> **校准回复：** “正如作者所承认的，评估仅限于合成基准测试。真实世界验证将增强贡献，但鉴于研究范围明确，并非必需。” [-0.5分]

### 2. 可复现性加分

**原则：** 支持复现的论文即使范围有限，也应获得认可。

**最低分数保障：** 若论文提供以下全部内容：
- 详细的方法描述
- 随机种子和超参数
- 代码/数据可用性（或明确声明）
- 置信区间和效应量

→ 分数不得低于6分（弱接受）

**理由：** 具有明确局限性但可复现的研究，比主张更广泛但缺乏透明度的研究更有价值。

### 3. 范围与质量

**原则：** 研究范围窄不等于质量低。

**校准：**
- 范围窄但严谨的研究 = 6-7分（弱接受至接受）
- 范围广但有缺陷的研究 = 4-5分（拒绝至边缘）
- 评估论文已做到的内容，而非其未尝试的内容

**示例：**
> **论文：** 针对某一特定现象在单一数据集上的严谨研究
>
> **未校准：** “研究范围有限，限制了其重要性。评分：5/10”
>
> **校准：** “在其所述范围内执行良好的研究。聚焦的调查研究为该子领域提供了清晰贡献。评分：6-7/10”

### 4. 合成数据现实

**原则：** 大多数机器学习/人工智能论文使用合成或基准数据；这本身并非缺陷。

**校准：**
- 标准基准测试是机器学习领域公认的方法论
- 仅当论文声称具有真实世界适用性但缺乏真实世界验证时才予以扣分
- 分析透彻的合成数据 > 分析粗糙的有限真实数据

## 语气校准

### 严重程度用语

| 情境 | 校准用语 | 避免用语 |
|-----------|---------------------|-------|
| 报告缺口 | “需要更清晰的报告” | “具有误导性” |
| 缺失要素 | “若能补充……将有所助益” | “未能……” |
| 范围限制 | “仅限于[情境]” | “存在根本性缺陷” |
| 不同解读 | “另一种解释” | “相互矛盾” |
| 表述不清 | “可以进一步阐明” | “令人困惑” |

### 建设性框架

**未校准（控诉式）：**
> “作者误导性地省略了关键基线，导致无法评估其真实贡献。”

**校准（建设性）：**
> “若能与[特定基线]进行比较，评估将更有说服力。这将有助于将所报告的15%改进置于更清晰的背景中。”

### 严重程度分布

在良好校准的评审中：
- **关键问题：** 占所有标注问题的比例低于5%（仅用于真正的无效性）
- **重大问题：** 占问题的20-30%
- **中等问题：** 占问题的40-50%
- **次要问题：** 占问题的20-30%

若您的评审中大部分为“关键”或“重大”问题，请重新校准。

## 常见过度扣分模式

### 模式一：因研究范围扣分

**触发条件：** 论文解决的是聚焦问题而非通用方案

**未校准：** 因“适用性有限”扣2-3分

**校准：** 范围影响重要性子分数（2/4而非3/4），而非整体有效性。若方法论严谨，最低分为6分。

### 模式二：因标准实践扣分

**触发条件：** 论文使用合成数据、标准基准测试或通用方法论

**未校准：** 因“缺乏真实世界验证”扣2分

**校准：** 这些是领域标准实践。仅当主张超出数据支持范围时才予以扣分。

### 模式三：对已承认问题双重扣分

**触发条件：** 论文明确讨论了某项局限性

**未校准：** 按作者不知情的情况全额扣分

**校准：** 肯定其承认行为，扣分降低50%以上

### 模式四：将中等问题灾难化

**触发条件：** 缺少部分实验或分析

**未校准：** “这从根本上削弱了所有主张的有效性”

**校准：** “补充[X]相关实验将增强结论的说服力”

## 评分对齐指南

### 与人类审稿人结果的映射

| AI评分 | 预期人类审稿结果 |
|----------|----------------------|
| 8-10 | 强烈接受 / 接受 |
| 7 | 接受 / 弱接受 |
| 6 | 弱接受 / 边缘接受 |
| 5 | 重大修改 / 边缘 |
| 3-4 | 拒绝 |
| 1-2 | 强烈拒绝 |

### 校准失准的警示信号

若出现以下情况，您的评审可能校准失准：
- 评分≤5但无法指出关键缺陷
- 超过3个问题被标记为“关键”
- 语气包含“误导性”、“根本性缺陷”、“无法评估”等词汇
- 对已承认局限性的扣分超过1分
- 具有可复现细节的论文评分低于6分

## 校准检查清单

提交评审前，请确认：

- [ ] 评分与所识别问题的严重程度一致
- [ ] 已承认的局限性获得降低扣分
- [ ] 中等问题未被标记为“关键”严重程度
- [ ] 语言具有建设性，而非控诉式
- [ ] 范围限制影响重要性而非严谨性
- [ ] 如适用，已应用可复现性加分
- [ ] 语气符合校准示例
- [ ] 人类审稿人是否会给出类似评分？

## 重新校准流程

若评审过于严苛：

1. **审查严重程度标签：** 将关键 → 重大 → 中等逐级降级
2. **检查承认奖励：** 降低对已承认问题的扣分
3. **应用可复现性最低分：** 严谨 + 可复现 = 最低6分
4. **重构语言：** 用建设性替代用语替换严苛措辞
5. **重新考虑范围扣分：** 范围窄 ≠ 质量低
6. **与示例比较：** 类似论文是否会获得类似评分？

## 实证基础

本指南基于AI评审与主要学术会议（ACL、NeurIPS、ICML等）实际人类同行评审的比较得出。

**关键发现：** 未校准时，AI系统评分往往比人类共识低约1.5分。主要原因：
1. 对已承认局限性过度扣分
2. 将范围限制视为根本性缺陷
3. 使用暗示不当行为的控诉式语言
4. 忽视积极贡献而聚焦于不足

**校准后：** 与人类评分的一致性从约60-70%提升至约85-90%。
