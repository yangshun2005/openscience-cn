# 科研基金申请技能

## 概述

撰写具有竞争力的科研基金申请提案的综合技能，重点关注美国四大资助机构：
- **NSF**（国家科学基金会）
- **NIH**（国立卫生研究院）
- **DOE**（能源部）
- **DARPA**（国防高级研究计划局）

## 本技能提供的内容

### 机构特定指南

针对每个资助机构的详细参考资料，包括：
- 使命与优先事项
- 评审标准与评分
- 提案结构与页数限制
- 预算要求
- 提交流程
- 提高竞争力的技巧

### 核心组件

- **具体目标页**（NIH）：关键的一页目标页模板与详细指南
- **项目摘要**（NSF）：概述、智力价值、更广泛影响等必需内容的模板
- **更广泛影响**：针对NSF同等权重评审标准的综合策略
- **预算说明**：人员、设备、差旅和物资的模板与示例
- **评审标准**：了解各机构评审专家的关注点

### 模板

即用型模板：
- NSF项目摘要
- NIH具体目标页
- 预算说明
- （更多模板开发中）

## 如何使用本技能

### 快速开始

撰写基金提案时，请指明机构和资助类型：

```
> 帮我写一份计算生物学研究的NSF提案
> 我需要为我的癌症研究项目起草NIH R01具体目标
> DOE ARPA-E概念论文中应包含哪些内容？
> 我正在申请DARPA项目——帮我规划提案结构
```

### 详细指导

针对特定组件的深入帮助：

```
> 请审阅我的NIH具体目标页
> 我的预算说明中应包含哪些内容？
> 在NIH重新提交中如何回应评审专家意见？
```

```
> NSF和NIH提案的主要区别是什么？

```

## 主要特点

### NSF提案

- **智力价值 + 更广泛影响**（同等权重）
- 实质性、可衡量的更广泛影响策略
- 研究与教育的整合
- 扩大STEM领域参与度
- 项目描述限15页（大多数项目）

### NIH提案

- **具体目标页**：最关键的一页（包含详细的一页指南）
- **研究策略**：重要性、创新性、研究方法等部分
- **前期数据**：R01申请的必要条件
- 严谨性与可重复性要求
- 模块化预算与详细预算
- 重新提交策略（A1申请）

### DOE提案

- **能源相关性**及与DOE使命的一致性
- **技术就绪水平**（TRL）
- 国家实验室合作
- 成本分摊要求（尤其是ARPA-E）
- 商业化路径
- 用户设施使用

### DARPA提案

- **DARPA难题**：高风险、高回报
- **海尔迈耶问答**：8个关键问题
- 项目经理参与（至关重要！）
- 基于阶段的结构与里程碑
- 技术转化规划
- 演示与原型

## 成功率指标

各机构的典型成功率：
- **NSF**：15-30%（因项目而异）
- **NIH R01**：总体约20%（早期研究者约27%）
- **DOE科学办公室**：20-40%（因项目而异）
- **ARPA-E**：2-5%（从概念论文到立项）
- **DARPA**：因项目差异很大

## 最佳实践

### 尽早启动
- NSF/NIH提案：截止日期前3-6个月开始
- DOE/DARPA提案：4-6个月（尤其是涉及国家实验室时）

### 获取反馈
- 模拟评审会议
- 本领域内外的同事
- 机构基金支持办公室
- 项目官员（适当时）

### 了解评审标准
- NSF：智力价值 + 更广泛影响（同等权重）
- NIH：重要性、研究者、创新性、方法、环境（1-9分制）
- DOE：技术价值、资质、预算、相关性
- DARPA：创新性、影响力、团队、可行性、转化

### 常见成功因素

✅ 清晰、有说服力的重要性和创新性
✅ 扎实的前期数据（NIH、DOE）
✅ 详细、严谨的方法论
✅ 现实的时间线和预算
✅ 具体、可衡量的成果
✅ 具有相关专业知识的强大团队
✅ 更广泛影响的整合（NSF）
✅ 技术转化计划（DOE、DARPA）

## 最大化效能的技巧

### NSF提案
1. 从具体目标/目的开始（即使不是必需）
2. 以与研究计划同等的严谨度撰写更广泛影响
3. 多用图表和示意图（使其易于快速浏览）
4. 明确回应两个评审标准
5. 获取本领域之外人士的反馈

### NIH提案
1. 首先完善你的具体目标页（10稿以上）
2. 包含充分的前期数据
3. 明确回应严谨性和可重复性要求
4. 主动识别潜在问题并提供备选方案
5. 确保你的目标相互独立但又协同增效

### DOE提案
1. 强调能源相关性和影响力
2. 包含量化指标（成本、效率、排放）
3. 制定部署或商业化路径
4. 考虑国家实验室合作
5. 回应技术就绪水平

### DARPA提案
1. 尽早联系项目经理（至关重要！）
2. 参加提案者日活动
3. 聚焦突破性创新（10倍提升，而非10%改进）
4. 明确回答海尔迈耶问答
5. 制定清晰的转化策略

## 有问题或疑问？

本技能力求全面，但可能无法覆盖每种具体情况。使用本技能时：

1. **具体说明**你的目标机构、项目和资助类型
2. **提供背景**关于你的研究领域和职业阶段
3. **提出后续问题**以获取澄清
4. **请求示例**针对你正在撰写的特定部分
