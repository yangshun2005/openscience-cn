# 开展科学研究

当任务是科学工作而非单一事实性解释时，请使用此技能。根据请求调整流程，不要强制每个任务都经历所有参考步骤。

## 开始

1. 阅读项目说明，并检查引用的文件、构建产物、先前会话、环境、连接器、算力及验证状态。
2. 明确所需结果，以及能够支撑该结果的最小证据或执行路径。
3. 在首次实质性操作前，阅读下方相关参考资料。
4. 确定验证关卡、是否确实需要任何持久化构建产物，以及任何新的权限或外部操作边界。
5. 执行、验证、仅保存请求的或真正可复用的输出，在重要时请求评审，处理反馈，并报告结果。

## 必需行为

- 除非有记录证明，否则绝不报告执行、检索、验证、评审或保存操作。
- 明确区分来源声明、直接观察、计算值、推断与假设。
- 保留原始输入及材料标识：单位、构建版本、版本号、标识符、筛选条件、连接方式、排除项及查询日期。
- 不要依赖隐藏的内核状态来生成持久化结果；在可行时保存代码并从声明的输入重新运行。
- 通过独立检查验证脆弱的检索、连接、模型、图表及构建产物。
- 使用最低必要权限。未经所需批准，不得暴露凭据或执行外部操作。

## 默认循环

```text
检查状态 → 确定目标与证据 → 执行 → 验证
→ 在需要时保存请求的或可复用的输出 → 按比例评审 → 纠正 → 报告
```

对于简单任务，多个阶段可能合并为一个，且无需构建产物。对于重要任务，不要仅为加快完成而省略验证；仅在请求或未来复用需要时创建持久化记录。
